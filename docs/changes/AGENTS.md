# Change Records

## Purpose

Owns active implementation progress and completed migration receipts.

## Local Contracts

- Each material request has one active `CHG-*.md` record until completed.
- Every CHG references a direct operator request or external ticket and its affected capability records.
- A phase may be marked done only with command or commit evidence.
- Move completed records from `active/` to `archive/`; do not edit archived records to describe later work.

## Child DOX Index

- `active/AGENTS.md` — current implementation authority.
- `archive/AGENTS.md` — completed receipts.
